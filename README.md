# SQL Detective Game 🕵️‍♂️

## 📌 Project Overview
SQL Detective Game is an interactive crime investigation system built using MySQL.  
Users solve a case by analyzing suspects, evidence, and witness statements using SQL queries.

---

![Case Intro](Assets/FirstPage.jpg)


## 🎯 Objective
To simulate a real-world investigation using SQL by linking multiple tables and deriving conclusions through queries.

---

## 🧠 Features
- Relational database design
- Evidence-based investigation
- SQL queries for filtering and analysis
- JOIN operations for linking data
- Subqueries for deeper insights
- Ranking suspects using window functions

---

## 🗂️ Database Structure
- **suspects** → Information about suspects
- **evidence** → Clues linked to suspects
- **witnesses** → Statements from witnesses
- **locations** → Crime-related locations

---

## 🔍 Investigation Flow
1. View suspects
2. Analyze witness statements
3. Examine evidence
4. Match suspects with clues
5. Rank suspects based on suspicion
6. Identify the culprit
